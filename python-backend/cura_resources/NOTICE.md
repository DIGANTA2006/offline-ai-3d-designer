# CuraEngine generic profile notes

The generic machine and extruder profiles in this folder are project-authored and inherit Cura's base `fdmprinter` and `fdmextruder` definitions. They are intended as generic defaults, not a certified profile for any particular printer. Confirm build volume, firmware, start/end G-code, nozzle, filament, temperatures and bed before printing. CuraEngine and its upstream definitions/license are from https://github.com/Ultimaker/Cura.
